First launch & joining a match
  1. Mac: unzip and open PeakRunner Launcher.app. Apple Silicon only. This playtest is not notarized; macOS may require approval in Privacy & Security after the first launch attempt. Only approve a download you trust.
  2. Windows: extract the ZIP and open PeakRunnerLauncher.exe. This unsigned x64 playtest has launch/render checks in Windows 11 ARM, not a full native x64 hardware certification.
  3. Linux: extract the .tar.gz and run peakrunner-launcher. Use a desktop session on Debian 12 or a compatible glibc 2.36+ distribution, with OpenGL for the launcher, Vulkan for the game, and the libraries listed on the download card.
  4. In the launcher, choose Install game, then Play. Updates wait until the game closes. Repair restores damaged files; Rollback restores the previous install, which may not match the live server. Launcher upgrades themselves still require a download. Standalone packages open directly without the launcher.
  5. Choose Find match, set your name, then select Springdale Central. You can also copy its address from the live host details and use direct connect.
  6. WASD moves, Space skis/jumps, right mouse jets, and left mouse fires. Use 1–3 for weapons and E for equipment. T opens public chat, Y opens team chat, Enter sends and Escape cancels.
  7. During a match, Escape opens the menu where you can change your name: 1–24 letters, numbers or spaces.

Native game required for multiplayer; this website is the match browser, not a browser version of the game. The server requires this release; older clients must update.
